# Events

The VA Events page lists upcoming VATSIM and IVAO events and helps you turn an event route into a Virtual Airlines flight.

## Browse an event

Events are shown for the next seven days. Select an event to open its details, including its provider, date, time, and available route intents. A route intent can represent an airport pair, arrivals, departures, or flights between a set of airports.

## Book an event flight

1. Open the event details.
2. Choose a route intent.
3. Select **Continue to VA Dispatch**.
4. Confirm the operation type and airline.
5. Choose an eligible aircraft and payload.
6. Review the route and event context.
7. Select **Book** and continue in My Flights.

The event supplies or locks the route so the resulting flight remains associated with the activity. An event reservation normally contains one free-flight leg.

## Reservation window and limits

You need a Virtual Airlines membership and an airline and aircraft that can operate the selected route. The reservation window opens one hour before the event and closes three hours after the event ends. A between-airports route intent can include up to 16 airports.

If an event has already been finalized or its provider data is unavailable, some route intents may not be bookable. Read the current event status shown by the page.

## Empty and error states

There may be no events in the next seven days, or an event may have no compatible route intent. Use the page's retry or refresh action when available. If a booking does not appear in My Flights, reload before submitting another booking.

## Event economics and results

An event can lock its route, timing, aircraft, or payload. Treat its Dispatch quote as the event-specific opportunity, then use [From Dispatch to Settlement](./flight-lifecycle) to understand validation and [Virtual Airlines Economy and Ticket Pricing](./economy-and-pricing) to understand which payload actually earns revenue.
