# Game Modes

FlyHub has two main ways to play: Free Flight Mode and Career Mode.

They both let you fly, track flights, earn results, and build history, but they are built for different styles of play.

## Quick comparison

| Mode | Best for |
| --- | --- |
| Free Flight Mode | Flexible flying, schedule browsing, casual routes, manual flights, and normal FlyHub XP. |
| Career Mode | Structured progression, airline employment, assignments, contracts, finances, and roleplay. |

## Free Flight Mode in plain language

Free Flight Mode is the open version of FlyHub.

You pick what to fly, when to fly, and how strict you want to be. You can browse schedules, book flights, build multi-leg itineraries, use manual/offline mode, track telemetry, and fill your normal logbook.

Most existing FlyHub guides about Schedules, Calendar, My Flights, Dashboard, Active Flight, Recovery Wizard, Profile, and Scoring apply to Free Flight Mode.

Free users can access Dashboard, Schedules, Calendar, and Tours. Premium users can also access VIP Ops, Manual Flight, and Historical Routes.

## Career Mode in plain language

Career Mode is the structured game mode.

Instead of freely choosing any route, you work through a pilot career. You interact with Career dispatch, assignments, employers, contracts, progression, money, and Career-specific rules.

Career Mode has its own save. Resetting it from Settings permanently deletes that Career save.

## Which mode should I start with?

Start with Free Flight Mode if you are new to FlyHub.

Use Career Mode when you want a stricter pilot progression system with more structure and consequences.

## Can I use both?

Yes. You can use Free Flight Mode and Career Mode for different kinds of sessions.

Keep in mind that Career Mode has its own Career progression and some pages behave differently from Free Flight Mode.
