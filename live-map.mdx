# Live Map

Live Map shows active FlyHub traffic on a world map.

Use it to watch your own flights and other visible pilots.

## What Live Map shows

Live Map can show:

- Free Flight traffic.
- Career traffic.
- Virtual Airline traffic.
- Online tracked flights.
- Offline/manual flights with synthetic progress.
- Route lines.
- Flight trajectories.
- Pilot cards.
- Network badges when detected.

## Traffic filters

The header lets you toggle:

- Free Flight traffic.
- Career traffic.
- Virtual Airline traffic.

The counter shows how many flights are visible out of the active flights. Turning off a traffic type hides its flights from the map.

If the map is reconnecting, the counter may show the last known traffic count.

## Search

When no flight is selected, you can search.

Search can match:

- Callsign.
- Airline ICAO.
- Pilot name.

Select a result to focus that flight on the map.

## Selecting a flight

Click a plane marker to select it.

The selected flight card can show:

- Airline logo or ICAO.
- Callsign.
- Aircraft type.
- Historical badge when relevant.
- Origin and destination.
- Progress bar.
- Nautical miles flown.
- Nautical miles remaining.
- Pilot name and avatar.
- Tier label.
- Network banner when VATSIM or IVAO is detected.

Click the map background or close button to clear the selected flight.

## Online flights

Online flights use recent simulator telemetry.

They show:

- Current position.
- Heading.
- Route progress.
- Trajectory when enough points exist.
- OFP route and waypoint labels when available.

If telemetry becomes stale, the flight may disappear from the map until it updates again.

## Offline flights

Offline flights can appear on Live Map using offline progress.

Because there is no live simulator telemetry, FlyHub estimates the position along the planned route.

Offline flights may show:

- Offline badge.
- Awaiting Check-In state.
- Estimated progress.
- Remaining distance.
- Current phase when available.

Offline markers move differently from online telemetry markers because the position is estimated.

## Map layers

The map can show:

- Plane markers.
- Callsign labels.
- Origin and destination dots.
- Route line.
- Actual or estimated trajectory.
- OFP route and waypoint labels.

The map style follows light or dark mode.

## Embed Live Map on your website

You can embed the public live map on any website that supports HTML iframes, including a custom website, WordPress, Squarespace, Webflow, or Wix. Visitors can watch traffic, search, and select flights without signing into FlyHub.

The embedded map keeps its interface clean. Set the traffic filters in the iframe URL; there is no filter toolbar or embed setup panel on the map.

<Steps>
  <Step title="Choose your map URL">
    Start with `https://flyhub.app/embed/live-map` to show all public traffic. Add the optional URL parameters below to choose an airline, aircraft type, airport, tracking method, or traffic types.

    For example, `?airline=FHW&traffic=virtual_airlines` shows only FlyHub First Wings Virtual Airline operations. Replace `FHW` with your own airline's three-letter ICAO code. Omit `airline` to include all airlines.
  </Step>
  <Step title="Add the iframe to your website">
    Copy the HTML example below and edit its `src` URL for your filters. Paste it into your website's custom HTML or embed element, or directly into the HTML of a custom website.

    For example, use a **Custom HTML** block in WordPress or an **Embed HTML** element in Wix. The example fills the available width and is 650 pixels high; adjust the height to suit your page.
  </Step>
</Steps>

For example, this embed shows FlyHub First Wings Virtual Airline traffic in the dark theme. Replace `FHW` with your airline's ICAO code, or remove `airline=FHW` to show traffic from all airlines:

```html
<iframe
  src="https://flyhub.app/embed/live-map?airline=FHW&amp;traffic=virtual_airlines&amp;theme=dark"
  title="FlyHub First Wings live traffic"
  width="100%"
  height="650"
  style="border:0"
  loading="lazy">
</iframe>
```

### Filter traffic using the URL

You can change the embed URL's optional settings:

| Setting | Example | What it does |
| --- | --- | --- |
| `airline` | `airline=FHW` | Shows flights belonging to that airline ICAO. |
| `aircraft` | `aircraft=A320` | Shows that aircraft type. |
| `airport` | `airport=EGLL` | Shows departures or arrivals at that airport. |
| `tracking` | `tracking=offline` | Accepts `all`, `online`, or `offline`. |
| `traffic` | `traffic=virtual_airlines` | Accepts `free_flight`, `career`, and `virtual_airlines`, separated by commas. Use `none` to hide every traffic type. |
| `theme` | `theme=light` | Accepts `dark` or `light`. The default embed theme is dark. |

Leave a filter out to include all flights for that filter. With no `traffic` setting, all three traffic types are included.

Filters combine: `airline=FHW&airport=EGLL` shows only FHW flights departing from or arriving at EGLL. Airline filtering matches the flight's airline ICAO, not a callsign prefix. Tracking refers to online telemetry or offline progress, not VATSIM or IVAO.

To change the displayed traffic, edit the iframe's `src` URL. These filters control the display of public traffic; they do not grant access to private data or require an API key.

The map refreshes automatically. The **FlyHub** link opens the full website live map in a new tab.

### An empty map or an embed that does not load

- **No live flights match these filters:** there may be no active flights for the selected airline, or the other filters may exclude them. Remove or broaden the filter parameters in the iframe URL.
- **Expecting the entire route network:** Live Map shows flights currently being tracked. It does not show every scheduled route when nobody is flying it.
- **Blank or cropped embed:** use the `/embed/live-map` URL and increase the HTML element's height. The regular `/live-map` page and other FlyHub pages cannot be embedded.
- **Your website blocks external embeds:** check that its embed settings allow content from `https://flyhub.app`.

## Refresh behavior

Live Map refreshes automatically.

It refreshes more often when traffic is active and less often when the page is hidden or quiet.

If a selected flight disappears or becomes stale, FlyHub clears the selection.

## Common mistakes

- Expecting offline flights to show real telemetry.
- Searching while a flight card is selected.
- Assuming every active flight is public or visible.
- Expecting a stale online flight to stay on the map forever.
