# Installing the Desktop App

FlyHub Desktop is the recommended companion app for PC pilots. It runs beside your simulator and handles telemetry, active-flight tracking, overlay prompts, and recovery snapshots.

## When you need it

Install FlyHub Desktop if you use:

- Microsoft Flight Simulator 2020 or 2024 on PC.
- X-Plane 12 on PC.
- The in-sim overlay.
- Automatic flight tracking.
- Crash recovery for active flights.

Console pilots can use FlyHub without desktop telemetry by completing flights manually.

## Where to download it

Download FlyHub Desktop from your FlyHub account.

1. Go to [flyhub.app](https://flyhub.app).
2. Log in to your FlyHub account.
3. Open the Dashboard.
4. Download FlyHub Desktop from the Dashboard.
5. Install it on the same PC where you run your simulator.

You can also download FlyHub from Flightsim.to:

[FlyHub Airline Career, Telemetry and Flight Tracking Platform](https://flightsim.to/addon/105102/flyhub-airline-career-telemetry-and-flight-tracking-platform)

## App updates

FlyHub Desktop updates automatically.

When an update is available, the app downloads and applies it for you. Keep the app updated so simulator tracking, overlays, recovery, and the X-Plane plugin tools stay current.

## Microsoft Flight Simulator

Microsoft Flight Simulator connects through SimConnect. No separate simulator plugin is required.

1. Start Microsoft Flight Simulator.
2. Open FlyHub Desktop.
3. Book and start a flight in FlyHub.
4. Spawn at the departure airport.
5. Keep FlyHub open while flying.

## X-Plane

X-Plane requires the FlyHub plugin.

1. Open FlyHub Desktop.
2. Go to Settings.
3. Find the X-Plane Plugin section.
4. Select your X-Plane folder.
5. Install or update the plugin.
6. Restart X-Plane.

See [X-Plane Plugin](/x-plane-plugin) for the full setup and troubleshooting guide.

## Overlay

The desktop app can show an overlay while you fly. The overlay can display landing feedback and the close-flight prompt after arrival.

## Recovery snapshots

If your simulator crashes during an online flight, FlyHub may offer recovery for a limited time. Reopen FlyHub quickly and look for Recover Flight on the Dashboard or My Flights.
