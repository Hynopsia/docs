# Career Mode Settings

The Career Mode tab appears for pilots who have access to Career Mode. It applies to the Career save currently selected in [Choose your career](/career-saves).

Use this tab carefully. The reset option permanently clears the selected save's Career progress.

## Change your Career name

Your Career name is the pilot name used inside the selected Career save. It can be different from your normal FlyHub username, and each save can have a different name.

1. Open Settings.
2. Select Career Mode.
3. Find Career Name.
4. Type the name you want to use.
5. Click Update Career Name.

FlyHub uses this name across that save's Career pages, assignments, contracts, and profile surfaces.

## Reset Career progress

Reset Career Progress clears the selected Career save's progress and sends that same slot back to onboarding. It does not empty the slot or change your other Career saves.

This reset permanently deletes from the selected save:

- Career assignments.
- Contracts.
- Dispatch plans.
- Finance and bank ledger data.
- Career notifications.
- Career flight history.
- Career logbook history.

## Important warning

Career reset is permanent. Once you reset the selected save, that Career progression cannot be restored. The save remains in its original slot and starts over during onboarding.

Use this only if you are sure you want to start that save again from the beginning. To empty a slot, use the delete action in [Choose your career](/career-saves).

## How to reset Career Mode

1. Open Settings.
2. Select Career Mode.
3. Find **Reset Career Progress**.
4. Click **Reset Progress**.
5. Read the warning dialog.
6. Type `reset my career` exactly as shown in the app.
7. Choose **Reset selected Career save**.

If you are unsure, cancel the dialog. There is no undo button after the reset starts. An active flight or unresolved recovery must be finished, cancelled, or resolved before this reset can begin.
