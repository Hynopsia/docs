# Career Mode Settings

The Career Mode tab appears for pilots who have access to Career Mode.

Use this tab carefully. The reset option permanently deletes your Career save.

## Change your Career name

Your Career name is the pilot name used inside Career Mode. It can be different from your normal FlyHub username.

1. Open Settings.
2. Select Career Mode.
3. Find Career Name.
4. Type the name you want to use.
5. Click Update Career Name.

FlyHub uses this name across Career Mode pages, assignments, contracts, and profile surfaces.

## Reset Career progress

Reset Career Progress deletes your current Career Mode save and sends you back to onboarding.

This reset deletes:

- Career assignments.
- Contracts.
- Dispatch plans.
- Finance and bank ledger data.
- Career notifications.
- Career flight history.
- Career logbook history.

## Important warning

Career reset is permanent. Once you reset your Career save, that Career progression cannot be restored.

Use this only if you are sure you want to start Career Mode again from the beginning.

## How to reset Career Mode

1. Open Settings.
2. Select Career Mode.
3. Find Reset Career Progress.
4. Click Reset Progress.
5. Read the warning dialog.
6. Type the confirmation phrase exactly as shown in the app.
7. Confirm the reset.

If you are unsure, cancel the dialog. There is no undo button after the reset starts.
