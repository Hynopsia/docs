# Simulator Overlay

Simulator Overlay is the small in-sim FlyHub overlay used during simulator flights.

It is different from Stream Overlay. Simulator Overlay is for you while flying. Stream Overlay is for OBS or stream viewers.

## What it does

Simulator Overlay can show:

- Landing feedback.
- Touchdown messages.
- Bounce or landing event messages.
- The Close Flight prompt after arrival.

This helps you finish a flight without leaving the simulator window.

## Turn it on or off

1. Open FlyHub Desktop.
2. Go to Settings.
3. Select Simulator.
4. Find Simulator Overlay.
5. Turn the switch on or off.

## When to use it

Use Simulator Overlay if:

- You want FlyHub messages inside the simulator.
- You do not want to alt-tab after landing.
- You want the Close Flight prompt to appear during taxi-in or after arrival.

## If the overlay does not appear

Try these steps:

1. Make sure FlyHub Desktop is open.
2. Make sure the Simulator Overlay switch is enabled.
3. Start your simulator.
4. Bring the simulator window to the front.
5. Start or resume your FlyHub flight.

The overlay attaches to the simulator window. If the simulator was just restarted, give FlyHub a few seconds to detect it again.

## Simulator support

Simulator Overlay is built for the desktop app and supported simulator windows. It is not a web-only feature.
