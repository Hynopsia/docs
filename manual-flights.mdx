# Manual Flights

Manual Flights is a premium Free Flight feature.

Use it when you want to build a route yourself instead of booking from the official schedule database.

## When to use Manual Flights

Use Manual Flights when:

- You want to fly an airline that is not part of the official FlyHub schedule roster.
- You want to fly any airport pair.
- You want a custom flight number.
- You want to choose from the full aircraft catalog.
- You do not want to wait for a route to be added to Schedules.

Do not submit non-roster airlines through Schedules suggestions. Premium users should use Manual Flights for those operations.

## Access

Manual Flights requires Captain.

Free users see a premium-required screen.

## Manual Flight step-by-step

1. Open Manual Flight.
2. Select a carrier.
3. Select origin airport.
4. Select destination airport.
5. Select aircraft.
6. Set the flight number.
7. Review the route preview.
8. Click Book.
9. Open My Flights to start the booking.

## Carrier selection

The Carrier section lets you search by airline name or ICAO.

Manual Flight carriers can include:

- Official FlyHub airlines.
- Manual-only airlines added for custom operations.

If an airline has multiple callsign prefixes or aliases, FlyHub may let you choose the prefix to use.

## Route selection

Choose:

- Origin airport.
- Destination airport.

Origin and destination must be valid airports and cannot be the same.

Use the swap button to reverse the route.

## Aircraft selection

Manual Flights uses the FlyHub aircraft catalog.

You can search by:

- Aircraft type.
- Manufacturer.
- Family.

Choose the aircraft you actually plan to fly.

## Flight number

Enter a flight number for the operation.

If multiple callsign prefixes are available, choose the prefix first.

FlyHub combines the prefix and number into the final callsign.

## Route preview

After route and aircraft are selected, FlyHub can preview the flight.

The preview can show:

- Route distance.
- Aircraft compatibility warnings.
- Airport or route warnings.

Review warnings before booking.

## Booking result

When you book a Manual Flight:

- FlyHub creates a custom booking.
- The booking appears in My Flights.
- You start and complete it like other Free Flight bookings.

Manual Flights are separate from Schedules. They do not add the airline or route to the official schedule database.

## Manual Flights vs route suggestions

| Need | Use |
| --- | --- |
| Missing current official route from the last 2 months | Schedules suggestion. |
| Older route or retired operation | Historical Routes suggestion. |
| Airline not in FlyHub official roster | Manual Flights. |
| Custom route you only want for yourself | Manual Flights. |

## Common mistakes

- Using Schedules suggestions for an airline that is not in the official roster.
- Forgetting that Manual Flights require premium access.
- Selecting the wrong callsign prefix when an airline has aliases.
- Booking before reviewing aircraft or airport warnings.
