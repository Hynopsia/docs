# Generate a SimBrief OFP

FlyHub can generate a SimBrief OFP from My Flights.

When the SimBrief flow succeeds, FlyHub can read your SimBrief Pilot ID from the new OFP and save it to Settings automatically.

## Before you start

Make sure you have:

- A FlyHub account.
- A booked flight in My Flights.
- A SimBrief account.

## Generate the OFP

1. Open FlyHub Desktop.
2. Go to My Flights.
3. Open the flight you want to plan.
4. Choose the SimBrief or OFP generation option.

After the OFP is generated, FlyHub saves the OFP data to the booking.

## Pilot ID auto-fill

If your SimBrief Pilot ID is empty in Settings, FlyHub can fill it automatically after a successful OFP generation.

This works because the generated OFP contains the SimBrief user ID. FlyHub reads that value and stores it in your profile for future flight plans.

## Sign in with email and password

If SimBrief or Navigraph opens a login window inside FlyHub Desktop, use your email and password login.

Google, Apple, Microsoft, or other OAuth sign-in methods may fail inside the desktop app login window. Email and password login usually works.

This is a Navigraph login-window issue, not a FlyHub issue.

## If OFP generation does not attach to your account

Try this:

1. Open Settings.
2. Go to General.
3. Check SimBrief Pilot ID.
4. If it is empty, generate the OFP again and make sure you sign in during the SimBrief flow.
5. If needed, manually enter your numeric SimBrief Pilot ID.
6. Click Save Changes.

## Units used for OFP generation

FlyHub uses your SimBrief Units setting from Settings \> General.

Choose Kilograms (KGS) or Pounds (LBS) before generating an OFP if you want the plan to use a specific unit system.
