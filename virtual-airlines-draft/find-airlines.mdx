# Find Airlines

Use **Find Airlines** to discover an airline that fits your pilot and apply to join it. The directory is intended for browsing and recruitment; it does not reserve a flight by itself.

## Search and filters

You can search by:

- Full name or short name
- ICAO code or callsign
- Home base

You can also filter by country, recruitment policy, or **Eligible for me**. The eligibility filter compares an airline's visible requirements with your VA pilot record. Use **Reset filters** to return to the full directory.

## What each result means

An airline result can show its logo, name, code, country, base, recruitment status, requirements, recent activity, and flights from the last 30 days. Requirements may include minimum flights, minimum hours, or a minimum average rating. A check mark means the displayed requirement is met; a warning means you may need more experience before applying.

The **Job Offers** panel refers to applications and recruitment decisions. It is not a salary offer or a guaranteed flight assignment.

## Visit a profile or apply

1. Select an airline to open its public profile.
2. Review the airline's identity, rules, fleet, network, and pilot information.
3. Select **Apply** or **Join**.
4. Read the current airline rules and requirements.
5. Confirm that you accept them.
6. Submit the application or join request.

If the airline uses automatic admission and you qualify, your membership can become active immediately. Otherwise, the request remains pending until the airline makes a decision.

## Requirements and application status

Reading directory results does not make you a member. Joining an airline unlocks the operations covered by that membership, while management tools depend on your manager role.

The directory displays up to 500 results at a time and does not provide page controls. Recent activity is measured over a 30-day window.

## If a result is missing

Check the search text and filters first. An airline may not appear because it is closed, outside the current recruitment policy, or not included in the current directory result set. If a request fails, reload the page and try again. Do not submit repeated applications while an earlier one is still pending.

## Choose for your play style

Look beyond the logo and flight count. Ask whether the airline's requirements, price philosophy, fleet, network, tour activity, and communication style match the kind of pilot you want to be. A large fleet does not automatically mean full flights, and a newer airline can be a good fit while it builds its reputation.
