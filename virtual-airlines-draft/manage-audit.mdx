# Manage Airline: Audit

There is no separate **Audit** tab in the current management workspace. The audit-style record is available as **Management history**. Use it to review changes made to the airline and system-generated administrative events.

## Where to find it

1. Open an active airline from **Airlines**.
2. Open its profile and select **Manage airline**.
3. Select **Management history** from the management header.

The current management navigation separates this history from:

- **Operations**, which is a working queue for flights and review tasks;
- **Market audit**, which analyzes demand, route health, and reputation;
- **Finance**, which shows cash, settlements, and the ledger.

Use [Management History](./manage-management-history) for the full guide. The audit record is read-only: it does not edit, delete, approve, export, or replay changes.

Access depends on your management role. If the link is not available, ask the airline owner or manager whether your role includes history access.
