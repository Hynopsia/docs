# Airline Profile: Network

The **Network** tab is a visual, read-only map of the airline's operating network. It shows the airports FlyHub can place on the map, open connections, and aircraft positioned at those airports.

## Network summary

The summary can include:

- **Airports**: network airports with valid map coordinates.
- **Open routes**: open connections between visible network airports.
- **Positioned**: aircraft whose last recorded airport is one of the visible stations, compared with the available fleet.

The map can mark the **Home base**, **Hub**, and a station's network ID. Lines and arrows show route direction. Curves can separate duplicate or opposite-direction routes.

## Explore an airport

1. Search by airport code, name, municipality, country, aircraft registration, aircraft type, or aircraft name.
2. Select a station from the list or a map marker.
3. Review its airport details, connections, and aircraft currently positioned there.
4. Select a connection to focus the opposite airport.
5. Use **Routes** to show or hide route lines and **Fleet** to control aircraft details on the map.
6. Use **Fit network** to return to the full network view.

This tab does not create, edit, suspend, import, or book routes. Select [Dispatch](./dispatch) when you want to operate a flight.

## Groups and visibility

A group's profile can aggregate routes from operating airlines while using the flagship's shared network of airports. The public map does not always identify which operating airline owns each connection. Routes without valid coordinates or routes that are not open may not appear.

## Empty and error states

If the airline has no mappable network airports, the page explains that airports added in management will appear here. If an airport has no aircraft or open connections, its detail panel says so. If a search has no match, clear the search.

The public map is a summary of the airline's network. If the profile cannot load, return to **My airlines** or reload it.
