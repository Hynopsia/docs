# X-Plane Plugin

X-Plane needs the FlyHub telemetry plugin for online tracking.

Microsoft Flight Simulator does not need this plugin. MSFS uses SimConnect.

## What the plugin does

The plugin lets FlyHub Desktop read X-Plane telemetry such as position, altitude, speed, aircraft state, touchdown data, and flight phase signals.

Without the plugin, FlyHub cannot run full online telemetry tracking for X-Plane flights.

## Install the plugin

1. Open FlyHub Desktop.
2. Go to Settings.
3. Select Simulator.
4. Find X-Plane 12 Plugin.
5. Click Select X-Plane.
6. Choose your X-Plane root folder.
7. Click Install.
8. Restart X-Plane.

Choose the main X-Plane folder. It should contain the X-Plane executable or the `Resources` folder.

## Update the plugin

FlyHub checks the installed plugin version when your X-Plane path is selected.

If an update is available:

1. Open Settings.
2. Select Simulator.
3. Find X-Plane 12 Plugin.
4. Click Update.
5. Restart X-Plane.

Restarting X-Plane is required because X-Plane loads plugins when the simulator starts.

## Check for updates manually

If the plugin is installed, a refresh button appears in the X-Plane plugin section.

Use it to check whether your installed plugin is current.

## Change the X-Plane path

Use Change Path if you moved X-Plane or selected the wrong folder.

1. Open Settings.
2. Select Simulator.
3. Click Change Path.
4. Select the correct X-Plane root folder.
5. Install or update the plugin again if needed.

## Verify the plugin in X-Plane

1. Start X-Plane.
2. Open the X-Plane Plugins menu.
3. Open Plugin Admin.
4. Look for FlyHub Telemetry.

If it appears and is enabled, FlyHub should be able to use X-Plane telemetry.

## If installation fails

Try these fixes:

- Close X-Plane before installing or updating.
- Make sure you selected the X-Plane root folder.
- If X-Plane is installed in Program Files, run FlyHub Desktop as Administrator.
- Check that your X-Plane folder is writable.
- Try installing again.

## If FlyHub says the plugin is missing

1. Confirm the X-Plane path in Settings.
2. Click Install.
3. Restart X-Plane.
4. Start your FlyHub flight again.

## If FlyHub says an update is required

1. Go to Settings > Simulator.
2. Click Update in the X-Plane 12 Plugin section.
3. Restart X-Plane.
4. Start your FlyHub flight again.

FlyHub may block online X-Plane tracking when the plugin is missing or outdated. This protects the flight from incomplete telemetry.

## Firewall note

The plugin communicates locally with FlyHub Desktop. If telemetry does not appear, make sure Windows Firewall or antivirus software is not blocking X-Plane or FlyHub Desktop.
