# Simulator Settings

The Simulator tab contains the desktop tools that connect FlyHub to your simulator and streaming setup.

These settings are mainly for FlyHub Desktop.

## Scenery Scanner

The Scenery Scanner opens a map where FlyHub can scan your installed simulator scenery packages.

Use it if you want FlyHub to know which airports and scenery packages are installed on your computer.

## Simulator Overlay

Simulator Overlay is an in-sim overlay. It can show landing toasts and the close-flight prompt while your simulator is open.

Use it if you want to finish flights without switching back to the main FlyHub window.

## Stream Overlay

Stream Overlay is different from Simulator Overlay.

Stream Overlay creates a local browser source for streaming software such as OBS or Streamlabs. It is for content creation and live streams.

## X-Plane Plugin

X-Plane needs the FlyHub plugin for telemetry. If you fly X-Plane, install the plugin from the Simulator tab before starting online tracked flights.
