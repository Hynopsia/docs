# Career Glossary

Use this page when a Career Mode term is unclear.

| Term | Meaning |
| --- | --- |
| Active employer | The airline you currently work for. |
| Active flight | The Career flight currently opened for tracking or offline completion. |
| Application | A request you send to an airline in Job Market. |
| Base | Your assigned company airport. |
| Bid Board | Monthly route preference system where you rank route lines for later award processing. |
| Current location | Where your Career pilot is currently positioned. |
| Dispatch | Page used to generate assignments, use Bid Board, or go on reserve. |
| Employment contract | Contract that activates normal line work. |
| Fatigue penalty | Career scoring penalty from fatigue pressure based on real tracked time, recent activity, rest, sim-rate usage, and anti-grind limits. |
| Grounded | Career flight duty is blocked until a required issue is fixed. |
| Interview | Timed question set used by some offers before a contract can proceed. |
| Jumpseat | Repositioning travel that moves your Career pilot without logging a flown assignment. |
| Ledger | Finance history showing income, expenses, loan payments, fees, and adjustments. |
| Line check | Recurrent company check ride that must score greater than 9.0/10. |
| Offer | Airline opportunity that may require interview, cost review, training, and contract signature. |
| Payroll | Weekly Career pay and deduction processing. |
| Pending contract | Contract waiting for your signature or required action. |
| Reputation | Career quality measure affected by performance and outcomes. |
| Reserve | Standby duty where Operations can call you for short-notice flying. |
| Roster | Scheduled Career assignments after Calendar planning. |
| Seniority | Your standing inside the airline, used for bidding and progression. |
| Strike | Weekly performance warning caused by low active-duty average. |
| Training contract | Contract that starts aircraft family training before full line work. |
| Type rating | Career permission to fly an aircraft family. |
| Union | Optional paid membership that can provide strike appeal and firing protection. |
