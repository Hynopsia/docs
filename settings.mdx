Settings is where you manage your FlyHub account, desktop app behavior, simulator tools, integrations, and Career Mode saves.

Most pilots should start with the General tab, then check Simulator if they use FlyHub Desktop with Microsoft Flight Simulator or X-Plane.

## Where to find Settings

1. Open FlyHub Desktop.
2. Click your profile area or open the app navigation.
3. Select Settings.

Settings is split into sections in a side menu:

| Section | Use it for |
| --- | --- |
| Profile | Your photo and the names other pilots see. |
| Account & security | Sign-in details, signed-in devices and your account data. |
| Flight tracking | How FlyHub starts and records your flights. |
| Flight planning | Your SimBrief account, OFP defaults and saved airframes. |
| Career Mode | Scoring rules, notifications and your Career save. |
| Virtual Airlines | Who can reach you inside Virtual Airlines. |
| Online networks | Link VATSIM and IVAO for live network badges and bonus XP. |
| Simulator & plugins | In-sim overlay, streaming tools and X-Plane plugins. |
| App | Window behaviour (close to tray) and Discord Rich Presence. |

Some sections only appear when they apply, for example Career Mode, Virtual Airlines or App. Admin users may also see Admin tools.

## Save changes

Some settings apply immediately. Profile and integration ID changes usually need the Save Changes button.

If you update your username, SimBrief Pilot ID, default units, tracking mode, VATSIM CID, or IVAO VID, click Save Changes before leaving the page.
