# Settings

Settings is where you manage your FlyHub account, desktop app behavior, simulator tools, integrations, and Career Mode save.

Most pilots should start with the General tab, then check Simulator if they use FlyHub Desktop with Microsoft Flight Simulator or X-Plane.

## Where to find Settings

1. Open FlyHub Desktop.
2. Click your profile area or open the app navigation.
3. Select Settings.

The page title in the app is Configuration. The tabs inside it are General, Career Mode, Integrations, and Simulator. Admin users may also see an Admin tab.

## What each tab is for

| Tab | Use it for |
| --- | --- |
| General | Profile, subscription, SimBrief defaults, tracking mode, close to tray. |
| Career Mode | Career pilot name and permanent Career reset. |
| Integrations | VATSIM, IVAO, and Navigraph linking. |
| Simulator | Scenery Scanner, Simulator Overlay, Stream Overlay, and X-Plane plugin. |

## Save changes

Some settings apply immediately. Profile and integration ID changes usually need the Save Changes button.

If you update your username, SimBrief Pilot ID, default units, tracking mode, VATSIM CID, or IVAO VID, click Save Changes before leaving the page.
